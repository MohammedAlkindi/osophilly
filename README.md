# OSO Philly

A one-page website for OSO Philly, the Omani Student Organization in Philadelphia. It is an early learning project, and the repository is archived.

## What the site contains

`index.html` is a single page with a header and these sections:

- Hero: the organization's purpose and three summary figures
- Mission: cards on cultural events, community support and work with other student groups
- Upcoming events: two event cards with date, time and place
- Leadership team: four roles, two of them still placeholders
- Contact: an email link and a link to the organization's Instagram account
- Footer: section links and the current year

The site lists Mohammed Alkindi as the organization's Web Manager. The events and team list were last changed in February 2026.

## Run locally

There is no build step and no server. Open `index.html` in a browser.

## Stack

- HTML and CSS (`styles.css`), with no framework
- One inline script that writes the current year in the footer
- A system font stack and inline SVG icons, so the page loads no files besides `styles.css`

## Status

Archived. The code is kept as a record of early work and is not maintained.
